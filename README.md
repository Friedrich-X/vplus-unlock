# V+ Unlock

## Download

Wähle deinen Browser:

| Browser               | Download                                                  |
| --------------------- | --------------------------------------------------------- |
| Chrome / Edge / Brave | [vplus-unlock-chrome.zip](dist/vplus-unlock-chrome.zip)   |
| Firefox (ab 140)      | [vplus-unlock-firefox.zip](dist/vplus-unlock-firefox.zip) |

## Installation

### Chrome

1. Zip entpacken
2. `chrome://extensions` öffnen, "Entwicklermodus" aktivieren
3. "Entpackte Erweiterung laden" und den entpackten Ordner wählen

### Firefox

1. `about:debugging#/runtime/this-firefox` öffnen
2. "Temporäres Add-on laden" und die `vplus-unlock-firefox.zip` (oder deren `manifest.json`) wählen

Hinweis: Temporäre Add-ons verschwinden beim Neustart von Firefox. Für dauerhafte Installation muss das Add-on über [addons.mozilla.org](https://addons.mozilla.org/developers/) signiert werden (geht auch als "unlisted", ohne öffentlichen Eintrag).
