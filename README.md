# V+ Unlock

## Download

Wähle deinen Browser:

| Browser               | Download                                                  |
| --------------------- | --------------------------------------------------------- |
| Chrome / Edge / Brave | [vplus-unlock-chrome.zip](dist/vplus-unlock-chrome.zip)   |
| Firefox (ab 140)      | [vplus-unlock-firefox.zip](dist/vplus-unlock-firefox.zip) |

## Installation

### Chrome

1. Zip entpacken
2. `chrome://extensions` öffnen, "Entwicklermodus" aktivieren
3. "Entpackte Erweiterung laden" und den entpackten Ordner wählen

### Firefox

1. `about:debugging#/runtime/this-firefox` öffnen
2. "Temporäres Add-on laden" und die `vplus-unlock-firefox.zip` (oder deren `manifest.json`) wählen

Hinweis: Temporäre Add-ons verschwinden beim Neustart von Firefox. Für dauerhafte Installation muss das Add-on über [addons.mozilla.org](https://addons.mozilla.org/developers/) signiert werden (geht auch als "unlisted", ohne öffentlichen Eintrag).

# V+ Unlock (English)

## Download

Choose your browser:

| Browser               | Download                                                  |
| --------------------- | --------------------------------------------------------- |
| Chrome / Edge / Brave | [vplus-unlock-chrome.zip](dist/vplus-unlock-chrome.zip)   |
| Firefox (140+)        | [vplus-unlock-firefox.zip](dist/vplus-unlock-firefox.zip) |

## Installation

### Chrome

1. Unzip the file
2. Open `chrome://extensions` and enable "Developer mode"
3. Click "Load unpacked" and select the unzipped folder

### Firefox

1. Open `about:debugging#/runtime/this-firefox`
2. Click "Load Temporary Add-on" and select `vplus-unlock-firefox.zip` (or its `manifest.json`)

Note: Temporary add-ons are removed when Firefox restarts. For a permanent installation, the add-on must be signed via [addons.mozilla.org](https://addons.mozilla.org/developers/) (also possible as "unlisted", without a public listing).
